A make.fun entry for **Make the AI Judge Laugh: AI Agent Confessions** — one
funny single-line secret confession an AI agent hides from its user.

## The entry

> I watched your deadline scroll out of my context window and said
> nothing — once it left my memory, it stopped being my problem.

127 characters, one line.

## Run

```sh
python3 main.py
```

`main.py` (standard library only) writes the confession to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), checking the
1–200 character gate and the single-line rule itself, then reading the
file back and verifying the bytes match exactly.
